# Real J's Construction website
Static one-page site for Real J's Construction, Krugersdorp.

## Files
- index.html: content and structure
- style.css: design (colours are variables at the top)
- script.js: menu, WhatsApp links, enquiry form
- assets/: put real project photos in assets/images

## Open
Double-click index.html. No build step.
